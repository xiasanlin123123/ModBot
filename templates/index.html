👋 先配置一下你的 API Key

这个助手不带内置额度，用你自己的 Key、花你自己的额度， 问多少都不受别人影响。Key 只保存在你自己这台电脑的浏览器里，不会上传到服务器。

1

去 DeepSeek 官网领一个 API Key

打开 platform.deepseek.com → 注册并登录 → 左侧「API keys」→ 创建一个，复制那串 sk- 开头的字符。（需要先充值几块钱才能调用）

2

粘贴到下面，点「开始聊天」

地址、模型名都已经帮你填好了，不用改。下次再打开这个页面会自动记住。

💡 在网吧或别人电脑上用完之后，记得回「⚙️ 设置」里点「清除本机保存的 Key」。

⚙️ 大模型配置

✅ 使用中

点一下会新建（或切到）对应的预设，地址和模型名自动填好，你只需再填自己的 Key。

豆包选 Ark；DeepSeek / OpenAI / Kimi / 通义 等选 OpenAI 兼容。不确定就用自动识别。

DeepSeek 的 deepseek-flash 支持图片，deepseek-v4-pro 不支持。不勾选时上传的图片不会发给模型。

Key 只保存在你自己这台电脑的浏览器里，不会上传到服务器。 选一个预设 → 改下面的配置 → 点「保存并使用」立即生效。
